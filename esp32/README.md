# Optional ESPHome Bluetooth proxy example

[stock-proxy.yaml](stock-proxy.yaml) is an example configuration for an ESP32
Bluetooth proxy. It has not been validated on physical hardware.

The [Home Assistant integration](https://github.com/swishyswoosh/mech-hacs#installation)
uses Home Assistant's existing Bluetooth connection.

For proxy configuration, see the official
[ESPHome Bluetooth proxy documentation](https://esphome.io/components/bluetooth_proxy/).
