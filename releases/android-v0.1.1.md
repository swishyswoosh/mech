# Mech for Android 0.1.1

Download **mech-android-0.1.1.apk** below to install Mech on Android 8 or newer
with Bluetooth Low Energy, including the Galaxy S9.

- Standalone controller with driving, dome controls, sounds, animations and lights.
- Drawn paths, saved action sequences and light presets.
- Landscape cockpit with sensor readouts and light/dark themes.
- Works offline without an account.

This is the first GitHub APK signed with Mech's release key. Android cannot
update an existing development or F-Droid installation signed with a different
key. Uninstalling it removes its locally saved settings, presets and battery
history. Future GitHub APKs signed with the same release key can update in place.

See the [installation instructions](https://github.com/swishyswoosh/mech/blob/android-v0.1.1/android/README.md).
The accompanying **SHA256SUMS** file lets you verify the APK download.
